# تصغير وتنظيم واجهة الزبون (/customer/ride) حسب النموذج المرفق

الهدف: مطابقة النموذج المرسل — عناصر مضغوطة ومنظمة في صفوف متساوية، أزرار أصغر، وكل المحتوى ضمن شاشة واحدة بدون طابع "صفحة هبوط". لا حذف لأي عنصر أو منطق — تعديلات مقاسات وتخطيط فقط.

## ما سيتغير

1. الشريط العلوي (صف واحد)
   - أفاتار دائري صغير 36px + مؤشر أخضر.
   - كبسولة واحدة تضم الإحصائيات الثلاث (المشاهدات / المستخدمين / طلبات اليوم) بفواصل رأسية خفيفة.
   - كبسولة الرصيد "DH 50" منفصلة، ثم زر الجرس (مع شارة) وزر الكرة الأرضية بحجم 36px مربّع الزوايا.

2. صف البطاقات السريعة (5 بطاقات بارتفاع موحّد)
   - "طلب رحلة" / نقاط النشاط مع شريط تقدّم رفيع / رقم اللوحة / نقطة الانطلاق / الوجهة.
   - نفس الارتفاع ونفس نصف القطر والحشو لجميع البطاقات، نص عنوان 9–10px وقيمة 12–13px، أيقونات دائرية 28px.
   - قابلة للتمرير أفقياً على الشاشات الضيقة مع بقاء الاصطفاف منتظماً.

3. الخريطة
   - بطاقة واحدة بحواف مستديرة، زر "تحديد على الخريطة" صغير أعلى اليسار، وأزرار تحديد الموقع و +/- مكدّسة أعلى اليمين بحجم 32–36px.

4. لوحة "خيارات إضافية" + التكلفة (كما في النموذج)
   - يسار: عنوان "خيارات اضافية" وتحته صف من 4 خلايا متساوية (نوع الرحلة / عدد الركاب / طريقة الدفع / الملاحظات) بارتفاع موحّد وأيقونة + قيمة + سهم.
   - يمين: صندوق التكلفة التقديرية مضغوط، السعر بخط 20–22px، وتحته سطرا المدة والمسافة بأيقونات صغيرة.

5. شريط الأمان
   - صف واحد: درع أخضر + نص "رحلتك آمنة" على اليمين، وثلاثة إجراءات (تتبع مباشر / مشاركة الرحلة / دعم 24/7) بأيقونات 28px وفواصل متقطعة، بأعمدة متساوية العرض.

6. أزرار الإجراء والتنقل السفلي
   - "احجز لاحقاً" زر ثانوي ضيق + "طلب سائق الآن" زر متدرّج عريض، كلاهما بارتفاع 44–48px بدل 56px.
   - شريط التنقل السفلي بخمس أيقونات صغيرة والزر الذهبي الأوسط بحجم أصغر قليلاً مع الحفاظ على التوهج.

## تفاصيل تقنية

- الملف الرئيسي: `src/pages/customer/RideStudioLayout.tsx` (تعديلات Tailwind على الأحجام/التباعد/التخطيط).
- تعديل بسيط اختياري على `src/components/BottomNav.tsx` لتصغير الأيقونات والزر المركزي.
- لا مساس بـ `LeafletMap.tsx` ولا بأي منطق Supabase/i18n.
- احترام إعدادات UI Studio الحالية (`radius`, `density`) بدل تثبيت قيم جديدة.
