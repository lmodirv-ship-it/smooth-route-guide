## الهدف

إضافة **كل** الأزرار التي ذكرتها إلى القائمة الجانبية للوحة الأدمن، وكل زر يفتح صفحة داخل اللوحة بنفس شكل الجداول في اللقطات (جدول داكن، شعار المزوّد، حالة، حدود يومية/شهرية، مفتاح تفعيل، أزرار اختبار/مفتاح/تعديل/حذف). لا حذف ولا تغيير لأي صفحة أو تصميم موجود.

## شكل الجدول الموحّد (كما في اللقطات)

مكوّن مشترك `AdminDataTable` يُعاد استخدامه في كل الصفحات الجديدة:

`#` · الشعار + الاسم (`provider · model_id`) · مجاني / غير مجاني · الحالة (مُشغّل / معطّل / فشل) · يحتاج مفتاح · RPM · يومي · شهري · الأولوية · مفتاح تفعيل (Switch) · إجراءات: ⚡ اختبار · 🔑 إضافة/تعديل مفتاح · ↗ فتح موقع المزوّد · 🗑 حذف

شريط علوي: **تحديث · تشغيل الكل · تعطيل الكل · توليد مفاتيح تجريبية · الأعمدة**
سطر إضافة سريع: `المزوّد ▾ | model_id | الاسم المعروض | Base URL | اسم السر | + إضافة`

## محتوى الصفحات الجديدة

- **نماذج الذكاء الاصطناعي**: كتالوج عالمي (OpenAI, Google Gemini, Anthropic, xAI, Mistral, DeepSeek, Qwen, Cohere, Perplexity, Groq, Together, Fireworks, OpenRouter, Meta Llama, Nvidia NIM, Azure OpenAI, Stability, ElevenLabs, Runway, Kling, Leonardo, FLUX, Replicate, HuggingFace…) بأنواع LLM/صور/فيديو/صوت.
- **النماذج المحلية**: Ollama / LM Studio / Stable Diffusion A1111 / llama.cpp / vLLM مع الحجم، أمر التشغيل (`ollama serve && ollama run …`) مع زر نسخ، حالة الاتصال، ورابط دليل التثبيت — كتالوج + مسارات تخزين محلية محفوظة في القاعدة.
- **AI with Admin / المحادثات**: دردشة الأدمن مع النماذج المفعّلة فقط، بث حي، Markdown، حفظ المحادثات؛ صفحة «المحادثات» تعرض السجل والأرشيف.
- **واجهة برمجة تطبيقات وكلاء**: تعريف الوكلاء، صلاحياتهم، مفاتيحهم، والأدوات المسموح بها.
- **فواتير الاستهلاك / قياس الاستهلاك**: عدد الطلبات، التوكنات، والتكلفة لكل نموذج ولكل يوم.
- **التراخيص / الباقات / الفواتير / التنزيلات / طلبات التسجيل / سجل الإجراءات / المراقبة**: جداول إدارية موحّدة تعتمد على الجداول الحالية عند وجودها (`driver_packages`, `payment_transactions`, `db_audit_log`) أو جداول جديدة عند الحاجة.

## التفاصيل التقنية

- جداول جديدة عند اللزوم: `ai_models`, `ai_local_models`, `ai_local_paths`, `ai_agents`, `ai_admin_chats`, `ai_admin_chat_messages`, `ai_usage_log`, `licenses`, `platform_packages`, `invoices`, `download_items`, `signup_requests`, `monitoring_checks`.
- RLS: كل شيء محصور بـ `has_role(auth.uid(),'admin')`، بدون وصول `anon`، مع `GRANT` في نفس الهجرة.
- المفاتيح تُخزَّن في القاعدة وتُعرض مقنّعة (`sk-••••1234`)؛ الاستدعاء الحقيقي داخل Edge Functions فقط.
- Edge Functions: `ai-model-verify` (اختبار المفتاح/الاتصال) و`ai-admin-chat` (بث الردود).
- الشعارات في `src/assets/ai-logos/`، والضغط على الشعار يفتح صفحة مفاتيح المزوّد.
- التنقّل: عناصر في `AdminLayout.tsx`، ومسارات lazy في `AdminRoutes.tsx` داخل `RequireRole allowed={["admin"]}`.
- التزام كامل بنظام i18n (ع/فر/إن/إس) ودون أي مساس بالتصميم الحالي.
